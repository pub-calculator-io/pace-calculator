Easily calculate running pace, distance, or finish time with our free Pace Calculator. Perfect for 5K, half-marathon, and marathon training plans.

[https://www.calculator.io/pace-calculator/](https://www.calculator.io/pace-calculator/)

== Usage ==

Add the Pace Calculator shortcode to your page, post or sidebar:

`[calcio_pace_calculator]`

Add the following code to your template where you would like the Pace Calculator to appear:

`<?php display_calcio_pace_calculator(); ?>`

== Installation ==

1. Upload the Pace Calculator /calcio_pace_calculator/ folder to the /wp-content/plugins/ directory.
2. Activate the Pace Calculator plugin through the "Plugins" menu in WordPress.
